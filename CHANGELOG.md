# История изменений

## 1.1.0

Пять пресетов вместо одного. Каждый снят с реального рилса — с замерами,
а не на глаз.

- **`cutout`** (REFERENCE-05, nick_saraev) — человек поверх карточки, голова выходит
  за её край на 16.6% высоты. Два слоя одного видео: исходник внутри карточки,
  версия без фона поверх. Скрипт `make_cutout.sh` для подготовки альфа-канала.
- **`scene`** (REFERENCE-04, saint4ai) — сцена сверху, фиксированная карточка
  спикера 45% внизу, бейджи накапливаются. Точечная сетка, ambient за объектами.
- **`split`** (REFERENCE-03, saint4ai) — панель 50% сверху, живое селфи снизу,
  прогрессивные субтитры.
- **`yapping`** (REFERENCE-02, aiwithsachi) — план 1.7с, субтитры по одному слову,
  сырые скриншоты фулскрином.
- **`story`** — поездки: Ken Burns на фото, вертикальная вписка через размытую
  подложку, импорт из Photos через osxphotos или apple-photos-mcp.

Ещё:
- Пять форматов головы как в CLONY: `split`, `split_reverse`, `cutout`, `jump`, `circle`
- Валидатор ловит безвкусицу: два акцентных цвета, `theme.glow`
- Ежедневная рутина `/reels:daily` + `run_daily.sh` для launchd/cron
- `reels-service` для VPS: очередь, Claude Code без Bash, Green API
- Команда `/reels:trip` для роликов из фото с телефона
