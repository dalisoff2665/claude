# yt-usa — американский YouTube с ИИ

12 скиллов для Claude Code: англоязычный YouTube-канал для США от ниши до монетизации.
Claude ищет темы, которые уже выстрелили, пишет сценарий на английском, озвучивает,
генерирует фото и видео, монтирует, делает превью и шортс, готовит публикацию
и разбирает, где уходят зрители. Публикуешь ты.

## Установка

```
/plugin marketplace add dalisoff2665/claude
/plugin install yt-usa@alisov-tools
```

Затем подключи vidIQ и YouTube-канал — `MCP.md`, проверка — `/yt-usa:setup`.

## 12 скиллов

| # | Скилл | Что делает |
|---|---|---|
| 1 | `yt-niche` | ниша, спрос и конкуренция по США, оценка дохода до съёмки |
| 2 | `yt-outliers` | видео ×10–×100 от среднего по своему каналу и их упаковка |
| 3 | `yt-brand` | имя, хэндл, аватар, баннер с безопасной зоной, описание, трейлер |
| 4 | `yt-script` | сценарий на английском, 5 хуков с оценкой, структура удержания |
| 5 | `yt-voice` | свой голос, клон, голос vidIQ, перевод своих видео HeyGen |
| 6 | `yt-visuals` | сток, генерация фото и видео-сцен, моушн-графика, персонаж |
| 7 | `yt-edit` | сборка 16:9 локально через ffmpeg: кадры, голос, музыка, субтитры |
| 8 | `yt-thumbnail` | превью: концепты, генерация, доработка, оценка, A/B |
| 9 | `yt-shorts` | шортс из длинного видео и с нуля |
| 10 | `yt-publish` | заголовок, описание, главы, раскрытие ИИ, расписание |
| 11 | `yt-retention` | секунда обрыва, фраза и одна правка |
| 12 | `yt-money` | YPP, AdSense, налог США и W-8BEN, inauthentic content, доход кроме рекламы |

Главный скилл `yt-usa` держит карту, порядок, цены в кредитах и правила.

## Первое видео — 10 шагов

1. `/yt-usa:setup` — vidIQ подключён, канал подключён, видно остаток кредитов.
2. `/yt-usa:niche` — бриф `channel/CHANNEL.md`, одобряешь.
3. `/yt-usa:outliers` — 10 тем по образцам, которые уже выстрелили.
4. `/yt-usa:brand` — аватар, баннер, описание. Загружаешь в Studio сам.
5. `/yt-usa:script 01` — выбираешь хук из пяти.
6. `/yt-usa:voice 01` — голос и субтитры.
7. `/yt-usa:visuals 01` — шот-лист с ценой, одобряешь, генерация.
8. `/yt-usa:edit 01` — готовое видео + контакт-лист.
9. `/yt-usa:thumb 01` и `/yt-usa:publish 01` — превью, заголовок, описание. Загружаешь сам.
10. Через 48 часов — `/yt-usa:retention <videoId>`: одна правка на второе видео.

## Файлы

- `MCP.md` — что поставить в Claude, сколько стоит, модель угроз
- `PROMPTS.md` — промпты для обычного чата Claude, если Claude Code нет
- `scripts/assemble.py` — сборка видео по `edit.json` (нужен только ffmpeg)
- `scripts/subs.py` — субтитры по словам (`pip install faster-whisper`)
- `templates/CHANNEL.md`, `templates/edit.example.json` — шаблоны
