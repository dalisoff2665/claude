# Голос

Вход: `videos/<NN>/script.md`. Выход: `videos/<NN>/voice.mp3` нормализованный, затем `subs.srt`.

## Какой путь выбрать

| Ситуация | Путь | Цена |
|---|---|---|
| Человек говорит по-английски | записать самому: петличка, тихая комната, по блокам | 0 |
| Не говорит, есть клон голоса | клон: ElevenLabs / HeyGen `create_speech` / vidIQ custom voice | по тарифу сервиса |
| Не говорит, клона нет | готовый голос vidIQ: `vidiq_voiceover_list_voices` → `vidiq_voiceover_generate` | 28 кредитов за 1000 знаков |
| Уже есть видео на русском с лицом | перевод HeyGen `create_video_translation`: его голос, его губы, английский | по тарифу HeyGen |

Свой голос или свой клон держит канал узнаваемым — и это сильный аргумент против
«inauthentic content». Чужой стоковый голос на всех роликах — слабое место.

Клонировать можно **только свой голос** или голос человека, который дал согласие.
HeyGen и ElevenLabs требуют подтверждения — это не обходится.

## Перед синтезом

1. Убери из текста пометки `[0:15]`, `B-roll notes`, ремарки.
2. Числа и сокращения — как их надо произнести: "$1,200" → "twelve hundred dollars",
   "vs" → "versus", "AI" оставь.
3. Разбей на блоки по 600–900 знаков по смысловым границам — проще переделать один кусок.
4. Посчитай цену заранее (для vidIQ: знаки / 1000, вверх, × 28) и назови её.

## vidIQ

```
vidiq_voiceover_list_voices          → свои клоны (isCustom=true) идут первыми, бери их
vidiq_voiceover_generate  script=<блок>  voiceId=<id как есть>
vidiq_job_poll  <mcpJobId>           → audioUrl, длительность
```

Скачай каждый `audioUrl` сразу в `videos/<NN>/voice/part-XX.mp3`.

## После синтеза

```bash
cd videos/<NN>
# склеить блоки с паузой 0.25 с
for f in voice/part-*.mp3; do echo "file '$f'"; echo "file '${CLAUDE_PLUGIN_ROOT}/templates/silence-250ms.wav'"; done > voice/list.txt
ffmpeg -y -f concat -safe 0 -i voice/list.txt -c:a libmp3lame -q:a 2 voice/raw.mp3
# голос на −16 LUFS (музыка подмешается в yt-edit, итог будет −14)
ffmpeg -y -i voice/raw.mp3 -af loudnorm=I=-16:TP=-1.5:LRA=11 -ar 48000 voice.mp3
# субтитры по словам
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/subs.py" voice.mp3 --lang en --out subs.srt
```

Прослушай начало и конец каждого блока: обрезанные слова, неверные ударения в именах,
«робот» на числах. Переделывай только испорченный блок.

## Перевод готового видео (HeyGen)

Для тех, кто уже снимает на русском: `create_video_translation` с целевым языком English —
сохраняет голос и подгоняет губы. Перед массовым переводом сделай один ролик и проверь:
термины, имена, юмор. Реалистичный перевод с липсинком — это «altered content»,
галочка раскрытия при загрузке обязательна (`yt-publish`).
