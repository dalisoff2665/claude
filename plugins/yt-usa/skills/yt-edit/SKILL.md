# Монтаж

Длинное видео собирается **локально**: `vidiq_compose` ограничен 240 секундами и стоит
1 кредит за 4 секунды, а ffmpeg — бесплатно и без ограничений.

## Вход

```
videos/<NN>/voice.mp3     нормализованный голос (yt-voice)
videos/<NN>/subs.srt      субтитры (scripts/subs.py)
videos/<NN>/shots/        картинки .png/.jpg и клипы .mp4
videos/<NN>/music.mp3     по желанию (vidiq_generate_music, 25 кредитов, или своя библиотека)
```

## 1. Монтажный план

Скопируй `${CLAUDE_PLUGIN_ROOT}/templates/edit.example.json` в `videos/<NN>/edit.json`.
Каждый шот — отрезок по времени голоса. Время ставь по `subs.srt`: шот начинается
на слове, о котором он, а не «примерно на 40-й секунде».

```json
{ "src": "shots/03-city.mp4", "start": 21.4, "end": 27.9, "trim_in": 2.0 }
{ "src": "shots/04-chart.png", "start": 27.9, "end": 33.0, "motion": "in" }
```

- `motion` для картинок: `in` (наезд), `out` (отъезд), `left`, `right`, `none`.
- Клип короче отрезка — зациклится; длиннее — обрежется.
- Шоты идут встык, без дыр: `end` предыдущего = `start` следующего. Скрипт проверяет.

## 2. Сборка

```bash
cd videos/<NN>
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/assemble.py" edit.json --out out/video.mp4
```

Скрипт рендерит каждый шот в 1920×1080 30 fps, склеивает, подкладывает музыку
с автоприглушением под голос (sidechain), сводит итог в **−14 LUFS** (уровень YouTube) и,
если в плане `"subtitles": {"burn": true}`, вшивает субтитры. По умолчанию субтитры
**не** вшиваются: SRT загружается в YouTube отдельно — так их индексирует поиск.

## 3. Проверка — своими глазами

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/assemble.py" edit.json --sheet out/sheet.jpg
```

Контакт-лист из 12 кадров по всей длине. **Открой `out/sheet.jpg` через Read** и проверь:
нет чёрных кадров, текст на картинках не обрезан, нет одинаковых кадров подряд дольше 10 секунд.
Плюс `ffprobe out/video.mp4` — длительность совпадает с голосом ±0.5 с.

## 4. Правки

Правишь `edit.json`, а не видео, и пересобираешь. Шоты кэшируются в `out/.cache/` —
пересобираются только изменённые.

## Короткие ролики через vidIQ

Трейлер канала, анонс, шортс до 240 секунд можно собрать в облаке: `vidiq_compose`
(сцены + voiceover + music + overlays, `format: landscape|vertical`). Источники — публичные HTTPS-ссылки
(сгенерированные vidIQ, или загруженные `vidiq_video_upload`, 0 кредитов). Цена — назвать до запуска.

## Вертикальный монтаж

Для шортс с лицом и сложной графикой — плагин `reels-factory` из этого же маркетплейса
(склейки по словам, Remotion, пресеты). Для нарезки из длинного — `yt-shorts`.
