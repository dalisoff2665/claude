# Сценарий для США

Вход: `channel/CHANNEL.md`, `videos/<NN>/brief.md` (тема, угол, образец-выброс).
Выход: `videos/<NN>/script.md`.

## 1. Исследование до текста

Без фактов сценарий превращается в воду. Собери в `brief.md` 5–10 конкретики: цифры, даты,
имена, примеры — с источником. Чего не знаешь — не придумывай, пометь `[проверить]`.

## 2. Пять хуков

Хук — первые 15 секунд. Напиши 5 разных:

| Тип | Пример |
|---|---|
| Результат вперёд | "This $12 tool replaced my $400 editor. Here's the catch." |
| Конфликт | "Everyone says start a faceless channel. The numbers say otherwise." |
| Вопрос с ценой | "Why do some 10-minute videos pay 5x more than others?" |
| Демонстрация | "Watch this: I type one sentence and get a full thumbnail." |
| История | "In March, a channel with 900 subscribers got 2 million views." |

Оцени каждый по 10-балльной шкале: конкретность, обещание, соответствие заголовку и превью,
понятность без контекста. Оставь 2 лучших, человек выбирает один. Хук **совпадает** с тем,
что обещают заголовок и превью, — иначе зритель уходит на 30-й секунде.

## 3. Структура удержания

```
0:00  Хук — обещание результата
0:15  Почему это важно зрителю + что будет в конце (открытая петля)
0:45  Блок 1 — самое сильное, не разогрев
      … блоки по 60–120 секунд, у каждого мини-итог и переход-крючок
      Середина: «payoff» — первая часть обещанного результата
-1:00 Главный результат / вывод
-0:20 CTA: одно действие (следующее видео по теме лучше, чем «подпишись»)
```

Длина: 150 слов ≈ 1 минута речи. 10 минут ≈ 1 500 слов.

## 4. Язык

- Разговорный американский: короткие предложения, you/your, глаголы вместо существительных.
- Конкретика вместо прилагательных: «$12/month», а не «affordable».
- Вычищай ИИ-интонации: "delve", "in today's fast-paced world", "it's important to note",
  "game-changer", "unlock", "dive in", "let's explore", тройки прилагательных, «not just X but Y».
- Спорные утверждения смягчай фактом, а не оговорками.

## 5. Через vidIQ (по желанию)

`vidiq_generate_script` (1 кредит за минуту) — дай `topic`, `title`, `concept` (наш угол)
и `research` (факты из брифа). Результат — черновик: прогони через пункты 2–4 и перепиши хук сам.

## 6. Формат script.md

```
# <рабочий заголовок>
## Hooks (score /10)
1. … — 8
2. … — 7
## Script
[0:00] HOOK …
[0:15] …
## B-roll notes
[0:15] screen recording of …
[0:40] generated: aerial shot of …
```

Пометки B-roll пиши сразу — по ним работает `yt-visuals`.
