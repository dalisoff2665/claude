# Выбросы: что уже выстрелило

Выброс — видео, которое набрало намного больше обычного для **своего** канала. Если маленький
канал на 8 тысяч подписчиков собрал 400 тысяч просмотров, значит сработала тема и упаковка,
а не аудитория. Это и копируется. Не содержание — схема.

## Поиск

```
vidiq_outliers  keyword="<тема из CHANNEL.md>"  language=en  contentType=long
                minEngagementRate=0.02  maxSubscribers=200000  limit=20
```

- `maxSubscribers` отсекает гигантов, у которых и средний ролик собирает миллион.
- `minEngagementRate=0.02` отсекает перезаливы и контент-фермы (у них 0.002–0.01).
- Шортс — тот же вызов с `contentType=short`.
- «Ещё такие же, как это видео» — `seedVideoId=<id>` вместо `keyword`.
- Какие смены заголовка или превью удвоили просмотры в нише — `vidiq_title_thumbnail_wins summary="<ниша>"`.

5 кредитов за вызов. Не открываются превью — передай ID в `vidiq_get_images`.

## Разбор топ-5

По каждому выбросу заполни строку в `channel/research/outliers.md`:

| Поле | Откуда |
|---|---|
| ×N от среднего | `breakout score` из ответа |
| Тема одной фразой | заголовок + описание |
| Формула заголовка | например «I tried X for 30 days», «Why X is dying», «$X vs $Y» |
| Превью: что в кадре | `vidiq_get_images` → опиши лицо, текст до 4 слов, контраст |
| Первые 30 секунд | `vidiq_video_transcript` — дословно, это хук |
| Что повторяем | 1 строка: что из этого станет нашим видео |

Полный просмотр с визуалом — `vidiq_video_watch` (25 кредитов). Делай только для одного,
самого близкого к нише ролика, и скажи цену заранее.

## Из выброса — в своё видео

Для каждой будущей темы пиши в `videos/<NN-slug>/brief.md`:

```
Образец: <ссылка>, ×<N>
Формула заголовка: …
Наш угол: чем мы отличаемся (свой опыт, свежие данные, другой зритель)
Обещание в первые 30 секунд: …
```

**Наш угол обязателен.** Видео, которое повторяет чужое по смыслу, — путь под политику
«inauthentic content». Повторяем структуру, тему и формат упаковки; содержание — своё.
