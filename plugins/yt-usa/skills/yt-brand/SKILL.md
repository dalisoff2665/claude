# Оформление канала

Источник правды — `channel/CHANNEL.md` (ниша, обещание, палитра). Всё кладёшь в `channel/brand/`.

## Размеры, которые проверяешь

| Элемент | Размер | Важно |
|---|---|---|
| Баннер | 2560×1440 | текст и лого только в центре **1546×423** — на телефоне видно только её |
| Аватар | 800×800 | показывается кругом 98×98: одно лицо или один знак, без мелкого текста |
| Водяной знак | 150×150, PNG | кнопка «подписаться» поверх видео |
| Превью видео | 1280×720 | см. `yt-thumbnail` |

После генерации проверяй файл: `ffprobe -v error -show_entries stream=width,height <файл>`.
Не тот размер — дотяни ffmpeg-ом (`scale` + `pad` или `crop`), а не новой генерацией.

## Имя и хэндл

Дай 10 вариантов: короткие (до 15 символов), произносимые американцем, без цифр и
подчёркиваний, с намёком на обещание. Проверка свободности хэндла — только руками в YouTube,
скажи об этом. Вместе с именем — слоган до 6 слов для баннера.

## Генерация картинок

Ищи генератор среди подключённых MCP (через поиск инструментов): `nano_banana_image`,
`bytedance_seedream_image`, `gpt_image_2`, `gemini_generate_image`. Если ни одного нет —
отдай промпты человеку, он вставит их в любой генератор.

**Баннер — промпт-скелет:**
```
YouTube channel banner, 16:9, 2560x1440. Wide calm background in <палитра>,
all key elements in a centered horizontal strip (safe zone), left and right thirds
nearly empty texture. Center: "<Channel Name>" in bold clean sans-serif, below it
"<slogan>" smaller. Subtle <предмет ниши> on the right of the safe zone.
No small text, no clutter, no watermark, premium, high contrast, readable at phone size.
```

**Аватар:**
```
Square 1:1 avatar, single bold <знак или лицо>, centered, fills 70% of frame,
solid <цвет> background, works as a 98px circle, no text.
```
Если формат с лицом — аватар делай из реального фото человека, а не генерацией:
`recraft_remove_background` → однотонный фон из палитры.

## Тексты на английском

- **Описание канала** (до 1000 знаков): первая строка — обещание и для кого;
  дальше 3 столпа, частота выхода, одна ссылка, контакт для бизнеса. Ключевые слова из
  `research/keywords.md` естественно, без перечислений.
- **Трейлер** для незнакомцев, 45–60 секунд: кто ты для зрителя → 3 примера пользы → когда выходят видео → подписка.
  Сценарий — в `channel/brand/trailer.md`, дальше по пайплайну `yt-voice` → `yt-edit`.
- **Ссылки:** максимум 2 — лид-магнит и соцсеть. Больше — рассеивает клики.

## Чек-лист перед загрузкой

- [ ] Баннер: текст внутри 1546×423, проверено на скриншоте с наложенной рамкой
- [ ] Аватар читается в круге 98 px
- [ ] Один акцентный цвет на всём оформлении
- [ ] Имя, хэндл, описание, ссылки — на английском, без опечаток
- [ ] Страна канала — реальная страна проживания

Загружает человек сам: YouTube Studio → Customization. Ты даёшь файлы и тексты.
