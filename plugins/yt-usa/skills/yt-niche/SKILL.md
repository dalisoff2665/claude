# Ниша для США

Результат — заполненный `channel/CHANNEL.md` (шаблон `${CLAUDE_PLUGIN_ROOT}/templates/CHANNEL.md`)
и `channel/research/keywords.md`. Без брифа остальные скиллы работают вслепую.

## Шаг 1. Три кандидата, а не один

Спроси одно: какие темы человек может вести год без отвращения — работа, хобби, то, что уже
умеет. Если не ответил, предложи сам три ниши из пересечения его опыта и спроса в США.
Не советуй нишу только потому, что она «дорогая».

## Шаг 2. Спрос и конкуренция — vidIQ

По каждому кандидату (5 кредитов за вызов):

```
vidiq_keyword_research  mode=research        keyword="<ниша по-английски>"  country=US
vidiq_keyword_research  mode=rising          niche="<ниша>"  period=month
vidiq_keyword_research  mode=questions       keyword="<ниша>"
```

Из ответа выпиши в `research/keywords.md`: 10 запросов с объёмом и конкуренцией,
5 растущих, 10 вопросов. Строки `Note:` из ответа vidIQ передай человеку как есть —
там правила чтения метрик.

**Хорошая ниша:** у запросов в США есть объём, конкуренция в средних значениях,
есть растущие хвосты, есть вопросы, на которые нет хорошего видео.

## Шаг 3. Деньги до съёмки

`vidiq_earnings_calculate` (5 кредитов) — это калькулятор, он ничего не тянет с YouTube:

```
subject=channel  monthlyViews=100000  category=<ближайшая>  country=US  language=en  shortsShare=0.3
```

Посчитай три сценария: 30 000 / 100 000 / 300 000 просмотров в месяц. Покажи вилку low/mid/high.
Пиши честно: «оценка vidIQ, не доход канала». Это сравнение ниш между собой, а не обещание.

## Шаг 4. Формат подачи

| Формат | Что нужно | Риск по политике YouTube |
|---|---|---|
| Лицо в кадре на английском | говорить на камеру | низкий |
| Лицо + перевод HeyGen с твоим голосом | снимать на родном языке | низкий, раскрытие ИИ при реалистичном переводе |
| Цифровой аватар | клон в HeyGen | средний: нужен свой сценарий и своя подача |
| Без лица: голос + B-roll/графика | сильный сценарий | выше всех: под ударом «inauthentic content», если ролики шаблонные |
| Анимация / ИИ-истории | генерация сцен + голос | средний: держит сюжет и персонаж |

Порекомендуй **один** формат и объясни одной строкой почему.

## Шаг 5. Бриф

Заполни `channel/CHANNEL.md`: ниша, зритель (возраст, боль, что ищет), обещание канала одной
фразой, 3 контент-столпа, формат, голос и тон, палитра, запреты, 10 первых тем.
Покажи бриф целиком и попроси одобрить. После одобрения — `yt-outliers`.

## Чего не делать

- Не выбирай нишу по одному запросу с большим объёмом — это может быть один вирусный ролик.
- Не обещай доход. Калькулятор — это ориентир, а не прогноз конкретного канала.
- Не ставь в настройках канала страну, в которой человек не живёт: страна канала влияет на
  AdSense и налоги. Аудитория может быть из США, страна канала — реальная.
