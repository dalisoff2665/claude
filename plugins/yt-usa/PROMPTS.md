# Промпты для обычного чата Claude

Для тех, у кого нет Claude Code. Подключи vidIQ в Settings → Connectors — промпты
используют его инструменты. Без vidIQ они тоже работают, но на знаниях модели, а не на данных.
Текст в `<угловых скобках>` замени своим.

---

## 1. Ниша для США

```
Я запускаю англоязычный YouTube-канал для аудитории США. Мой опыт: <что умею и люблю>.
Предложи 3 ниши на пересечении моего опыта и спроса в США. По каждой через vidIQ:
keyword_research (country=US) — 10 запросов с объёмом и конкуренцией, rising — 5 растущих,
questions — 10 вопросов; earnings_calculate для 30k/100k/300k просмотров в месяц.
Сведи в таблицу и порекомендуй одну нишу и один формат (лицо / аватар / голос + B-roll / анимация).
Перед вызовами скажи, сколько кредитов уйдёт.
```

## 2. Что уже выстрелило

```
Найди через vidiq_outliers 20 длинных англоязычных видео по теме «<тема>»
от каналов до 200 000 подписчиков, minEngagementRate 0.02. Для топ-5: во сколько раз выше среднего,
формула заголовка, что на превью, дословно первые 30 секунд (vidiq_video_transcript).
В конце — 5 тем для моего канала: формула та же, угол свой.
```

## 3. Оформление канала

```
Канал: <ниша>, обещание: <одна фраза>. Дай 10 вариантов названия (до 15 символов, легко произносятся
американцем), слоган до 6 слов, описание канала на английском до 1000 знаков,
и промпты для баннера 2560×1440 (весь текст в центральной зоне 1546×423) и аватара 800×800 (читается кругом 98 px).
Палитра: <цвета>, один акцент.
```

## 4. Сценарий

```
Напиши сценарий YouTube-видео на английском для США, <N> минут (150 слов = 1 минута).
Тема: <тема>. Наш угол: <чем отличаемся>. Факты: <список с источниками>.
Сначала 5 разных хуков на первые 15 секунд, оцени каждый по 10-балльной шкале.
Структура: хук → зачем это зрителю + что будет в конце → блоки по 60–120 с с мини-итогом →
результат → один CTA. Без слов delve, unlock, game-changer, dive in, «in today's fast-paced world».
Пометки B-roll в квадратных скобках с таймкодом.
```

## 5. Превью

```
Видео: «<заголовок>». Предложи 3 разных концепта превью: что в кадре, эмоция, текст до 4 слов,
который не повторяет заголовок. Потом сгенерируй выбранный через vidiq_generate_thumbnail
(landscape) по стилю этих превью: <ссылки на превью выбросов>.
```

## 6. Заголовок и описание

```
Видео про <тема>, хук: <хук>. Через vidiq_generate_titles (regionCode US, 8 вариантов)
и vidiq_score_title для лучших трёх выбери заголовок до 60 знаков. Напиши описание:
первые 2 строки — обещание и ключевая фраза, потом 3–5 строк, главы, ссылка, 3 хэштега.
Скажи, нужно ли ставить «Altered or synthetic content» для этого видео и почему.
```

## 7. Где уходят зрители

```
Вот удержание моего видео (CSV из YouTube Studio → Advanced mode → Export) и субтитры (SRT).
Найди: сколько осталось к 0:30, главный обрыв после 0:30 — секунду, процент, фразу ±5 секунд,
пики пересмотра. Ответ: одна правка на следующее видео. Не список советов — одна правка.
```

## 8. Монетизация

```
Канал англоязычный, я живу в <страна>. Распиши: пороги YouTube Partner Program обоих уровней,
что нужно в AdSense, как заполнить налоговую информацию США (W-8BEN) и откуда взять ставку по договору,
что проверить по политике inauthentic content для канала с ИИ, и 3 способа дохода кроме рекламы
для моей ниши <ниша>. Без обещаний дохода.
```
