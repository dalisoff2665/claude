Веди человека по запуску канала. Тема: `$ARGUMENTS` (может быть пусто). Открой скилл yt-usa — там карта и правила.

Порядок, по одному этапу за раз, каждый заканчивается тем, что человек одобряет результат:
1. `/yt-usa:setup` — что подключено.
2. Скилл yt-niche → `channel/CHANNEL.md` (шаблон `${CLAUDE_PLUGIN_ROOT}/templates/CHANNEL.md`).
3. Скилл yt-outliers → `channel/research/outliers.md` и 10 тем.
4. Скилл yt-brand → имя, аватар, баннер, описание.
5. Первое видео: yt-script → yt-voice → yt-visuals → yt-edit → yt-thumbnail → yt-publish.
6. Из него 3 шортс — yt-shorts.

Перед каждым платным шагом называй цену в кредитах. В конце каждого ответа — «Следующий шаг: …».
