# doubt-driven

Скилл [doubt-driven-development](https://github.com/addyosmani/agent-skills/blob/main/skills/doubt-driven-development/SKILL.md)
из addyosmani/agent-skills (MIT), один, без остального набора. Копия зафиксирована на коммите `301b02b`:
изменения автора сами не приедут.

## Что делает

Перед тем как нетривиальное решение останется в коде (ветвление, граница сервисов, «это безопасно»,
деплой, миграция), Claude формулирует утверждение, отдаёт артефакт и контракт свежему агенту
с задачей «найди, что здесь не так», разбирает находки и останавливается максимум через 3 круга.
На переименования, форматирование и чёткие инструкции не срабатывает.

## Установка

```
/plugin marketplace update alisov-tools
/plugin install doubt-driven@alisov-tools
```

## Что учесть

- **Стоит токенов**: каждый круг — отдельный субагент. Срабатывает на высоких ставках
  (безопасность, деплой, необратимые операции), а у тебя они в каждой второй задаче.
- **Спрашивает про второе мнение другой моделью** (Gemini CLI, Codex CLI) в каждом круге — так задумано
  автором. Ответ «skip» — и идёт дальше. Внешний CLI запускается только после твоего «да» на конкретную команду.
- Персонажи-ревьюеры из `agents/` апстрима не поставлены: скилл берёт обычного свежего субагента.
