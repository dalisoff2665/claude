Правка монтажа: **$ARGUMENTS**

Это правка `edl.json`, а не пересборка. Порядок:

1. Прочитай текущий `edl.json`.
2. Найди элементы, которых касается правка.
3. Измени только их — через Edit, точечно. Остальной план не трогай.
4. Если правка двигает тайминг — проверь, что соседние элементы не наложились.
5. Провалидируй и отрендери:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/validate_edl.py" edl.json && \
bash "${CLAUDE_PLUGIN_ROOT}/scripts/render.sh"
```

Скажи одной строкой, что изменил. Не показывай весь JSON.
