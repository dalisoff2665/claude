Ролик-воспоминание. Период: **${1:-последние 7 дней}**. Название: **${2:-поездка}**

## 1 · Отбор

**Если подключён apple-photos-mcp — работай через него, это лучший путь.**
Он даёт то, чего нет в голом экспорте: фильтр по людям, по месту, по GPS-радиусу
и по `minScore` — собственной эстетической оценке Photos.

```
query   fromDate/toDate за период, notScreenshot, minScore 0.5, newestFirst
        → список UUID с датами и местами
```

Дальше **get-thumbnail на кандидатов** — превью приходит картинкой прямо в диалог,
ничего не экспортируется. Смотри и отбирай: один кадр из серии похожих,
лица крупно важнее общих планов, смазанное выбрасывай.

`find-duplicates` перед отбором — если снимал сериями, там половина — дубли.

Потом экспорт только выбранного:

```
export  uuid: [...отобранные], dest: "~/Desktop/trip-export"
```

и подготовка файлов:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/pipeline/photos_import.py" \
  --from-dir ~/Desktop/trip-export --out raw/trip
```

**Если MCP нет** — забирай всё за период и отбирай по контактным листам:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/pipeline/photos_import.py" --days 7 --out raw/trip
```

Тогда **обязательно открой через Read каждый лист** в `raw/trip/sheets/`.
Отбирать по именам файлов бессмысленно — половина снимков смазанные дубли.

В обоих случаях на ролик 40–50 секунд нужно **14–18 кадров**, не больше.

## 2 · Разложить

Читай `raw/trip/media.json` — даты, места, отметки «избранное».
Хронология: приезд → день → вечер → отъезд. Порядок по времени почти всегда
сильнее придуманной драматургии.

Пресет `story`:
- фото держится **2.2–3.2 секунды**
- `motion` чередуй: наезд, снос влево, отъезд, снос вправо.
  Три наезда подряд читаются как глюк
- видео режь до 3–5 секунд, самое живое место
- титр `place` только при смене локации
- первые 2 секунды — самый сильный кадр, не общий план

## 3 · Звук

Музыка из `assets.json`, `gain_db: -20` — она ведущая, речи нет.

Если записал голосовой комментарий:

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/transcribe.py" raw/voice.m4a --out words.json
```

и ставь `captions_style: "progressive"`, музыку приглуши до −28.
Без голоса субтитры не нужны — титров места хватит.

## 4 · Собрать

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/validate_edl.py" edl.json
bash "${CLAUDE_PLUGIN_ROOT}/scripts/render.sh"
```

## Приватность

Личные фото, часто с детьми. **Не заливай результат в Cloudinary без явной просьбы** —
там публичные URL по умолчанию. Файл оставь в `out/reel.mp4` и скажи, где он.

Если MCP подключён — не включай `APPLE_PHOTOS_MCP_ENABLE_WRITES`.
Для монтажа нужно только чтение и экспорт.
