Собери новый ролик. Тема: **$ARGUMENTS**

Не начинай работу, пока не выбран формат. Спроси через **AskUserQuestion**,
одним экраном, три вопроса:

## Вопрос 1 — раскладка

| Вариант | Что это |
|---|---|
| `scene` — сцена + карточка | лицо в квадрате внизу 45%, сверху бейджи и мокапы. Выглядит как студия |
| `cutout` — вырез поверх карточки | голова выходит за край карточки. Самый дорогой вид, нужен ровный фон |
| `topslot` — полоса сверху | скриншот узкой полосой 33%, лицо доминирует. Для перебора многих экранов |
| `yapping` — поток | план 1.7с, субтитры по одному слову. Быстро и живо |

Если тема про **перебор инструментов или список** — подскажи `topslot`.
Если про **одну систему по шагам** — `scene`.

## Вопрос 2 — что с лицом

| Вариант | Когда |
|---|---|
| Свой дубль | снял сам, файл в `raw/aroll.mp4` |
| Аватар HeyGen | съёмки не было, текст озвучит аватар |
| Уже вырезан | есть `.webm` с альфой для `cutout` |

## Вопрос 3 — длина

`30 с` коротко · `45 с` стандарт · `60 с` подробно
