# Что снимать и что давать Claude Code

Это ответ на «что ему дать — видео? скриншоты? демо?». Дать надо **четыре вещи**,
и снимать их надо конкретным образом.

## 1. A-roll — один непрерывный дубль

GH4 на штативе, DJI Mic 2, Ulanzi сзади на стену цветным пятном.

- **Один дубль на весь ролик**, 50–70 секунд сырого. Не снимай по кускам «на монтаж» —
  нарезку сделает Claude, а склеивать разные дубли по свету и по кадру дороже, чем вырезать паузы.
- **Запнулся — не останавливайся.** Сделай паузу 1.5 секунды и повтори фразу заново.
  Пауза попадёт в `gaps` в `words.json`, Claude вырежет и фальстарт, и паузу.
- **Смотри в объектив всё время.** Взгляд вниз = кадр нельзя использовать под склейку.
- Оставь **воздух сверху** — нижние 500 px по вертикали уйдут под субтитры,
  верх под титр. Голова в верхней трети кадра, не по центру.
- Снимай **4K**, если GH4 тянет. Рендер вертикальный 1080×1920, запас нужен для кропа и зумов.

**Чего не делать:** не снимай отдельно «интро», отдельно «шаг 1». Это ручной монтаж
и есть, ты его и пытаешься убрать.

## 2. Демо-скринкасты — длинные и сырые

- Пишешь экран **целиком и медленно**, как будто объясняешь. 2–4 минуты на шаг это нормально.
- **Не ускоряй при записи** — ускорение задаётся в EDL полем `speed` (2.5–4×).
  Если ускоришь при записи, Claude уже не сможет замедлить важный момент.
- Курсор крупный, включи подсветку кликов.
- Тёмная тема терминала, светлая — интерфейсов. Это то, что делает мокапы контрастными.
- Клади в `raw/demo/`. Потом `broll_index.py` → откроешь контакт-шиты → допишешь `moments`.

## 3. Статичные скриншоты — для слайдов

Скриншоты, которые пойдут **внутрь мокапа окна** на слайдах: `raw/shots/*.png`.
Это не то же самое, что скринкаст. Слайд — дизайн-карточка, скриншот в ней декоративный,
читается за секунду. Бери самый выразительный кадр: результат, а не процесс.

Retina, 2×, без личных данных в кадре (проверь вкладки браузера и уведомления).

## 4. Референс — чужой ролик, чей монтаж нравится

```bash
python3 scripts/ref_analyze.py <ссылка> --out ref/новый/
```

Открываешь `grid.jpg`, размечаешь типы планов, `REPORT.md` кладёшь в контекст Claude Code.
Копируется **структура и ритм**, не содержание.

## Как запускать монтаж

```
Прочитай CLAUDE.md, ref/REFERENCE-01.md, words.json, broll.json, assets.json.
Собери edl.json на ролик про <тема>.
Ритм — как в референсе. Пять шагов с eyebrow-счётчиком.
Слайды с анимированным фоном из assets.backgrounds.
Чип на каждое название инструмента, лого из assets.logo_index.
Потом провалидируй и отрендерь.
```

Дальше он работает сам. Твоя правка идёт **в edl.json**, а не «перемонтируй заново»:
«сделай слайд 02 на 2 секунды короче, добавь чип с лого Airtable на слове база» → он правит
три строки JSON и рендерит заново. В этом вся разница с обычным монтажом —
правка стоит 20 секунд, а не полчаса.

## Чеклист перед запуском

- [ ] `words.json` собран
- [ ] `broll.json` с заполненными `moments`
- [ ] `assets.json` свежий
- [ ] референс разобран
