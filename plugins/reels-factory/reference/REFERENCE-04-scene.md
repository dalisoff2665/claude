# Референс 04 — сцена + карточка спикера (saint4ai)

Четвёртый пресет. Тот самый, под которым в комментариях пишут «монтаж огонь, как такой сделали?»,
а автор отвечает: «Ролик полностью смонтирован с ИИ».

Разобран рилс «ИИ-ассистент в директ» (instagram.com/p/Ddb6IzFNWU3).

## Технические факты

| | |
|---|---|
| Длина | 56.5 с |
| Формат | 720×1280, 30 fps |
| Громкость | −14.2 LUFS |
| Перестроений сцены | ~16 |
| Средний интервал | 3.5 с |

## Геометрия — снята пипеткой по кадру

```
┌─────────────────────────┐  0%
│                         │
│      СЦЕНА              │  ← бейджи, мокапы, схема, крупные цифры
│      0 – 70%            │     фон меняется целыми сценами
│                         │
│   Третий — сервер.      │  ← субтитр на 57% высоты
│                         │
├─────────────────────────┤  74.5%
│   ┌───────────────┐     │
│   │   лицо 45%    │     │  ← карточка спикера, ЦЕНТРИРОВАНА
│   └───────────────┘     │     ширина 45% кадра, поля по 27.5%
└─────────────────────────┘  98.4%, отступ снизу 1.6%
```

- Карточка спикера: **45% ширины, почти квадрат, скругление ~42 px** (в макете 1080×1920)
- **Позиция карточки не меняется весь ролик.** Никогда.
- Сцена сверху перестраивается, лицо стоит на месте

Вот почему ролик «монтируется ИИ»: монтировать нечего. Есть один непрерывный дубль
в фиксированной рамке и сцена, которая собирается кодом.

## Палитра

| Роль | Цвет |
|---|---|
| Фон сцены | `#101114` — почти чёрный, но с синевой, не `#000` |
| Пилюля бейджа | `#131217` + тонкая светлая обводка сверху |
| **Системный акцент** | **`#3FE8C2`** — мятный |
| Цвет бренда | `#FA792B` — приходит только из лого Zernio |
| Текст | `#FFFFFF` |
| Подчёркивание в субтитре | мятное |

**Уточнение к правилу одного акцента:** системный акцент здесь один — мятный.
Оранжевый не второй акцент, а цвет чужого логотипа. Фирменные цвета брендов
в иконках не считаются и не ломают палитру. Ломает — когда ты сам красишь
свои заголовки в третий цвет.

## Фактура фона

Не линейная сетка, как в референсе 03, а **точечная**: точки `rgba(255,255,255,0.05)`
с шагом 22 px. Плюс по краям кадра мягкие ambient-пятна — тёплое сверху справа,
холодное справа по центру. Радиус огромный, непрозрачность ~8%.

Это не свечение элементов. Это подсветка **фона за сценой**, и разница принципиальная:
glow на объекте читается как сток, ambient за объектом читается как студия.

## Бейдж — главный строительный блок

```
┌──────────────────────────────┐
│ (◉)  Claude Code             │   пилюля #131217, radius 999
└──────────────────────────────┘   высота ~62 px, padding 22/34
                                   иконка круглая слева, Ø 44
                                   текст белый, 34 px, вес 700
```

Варианты:
- иконка = логотип инструмента (из твоей таблицы `logos`)
- иконка = номер шага, мятный кружок с чёрной цифрой

## Схема растёт по ходу речи

К 37-й секунде на сцене одновременно: `Claude Code` сверху, под ним `Zernio`
и `OpenRouter`, ниже `③ сервер` и 3D-рендер серверной стойки. Соединены
**пунктирными дугами** `rgba(255,255,255,0.25)`.

Бейджи не заменяют друг друга — они **накапливаются**. Зритель видит, как из
отдельных кусков собирается система. Это и держит до конца лучше любых склеек.

## Сцены меняют фон целиком

| Время | Фон | Что |
|---|---|---|
| 0–4 с | тёмный | заголовок + бейдж `Claude Code` |
| 4–6 с | **оранжевый** | «вместо ManyChat», `$25` |
| 6–12 с | тёмный | мокапы телефона со скриншотами |
| 12–14 с | тёмный | крупно `до $1 409` |
| 14–16 с | **светло-серый** | «3 лёгких шага» |
| 16–48 с | тёмный | схема накапливается |
| 50–56 с | **светлый** | тумблер «вручную / автомат» |

Смена фона — это глава. Четыре смены на 56 секунд.

## Субтитры

Белые, ~40 px, по центру на 57% высоты. Ключевое слово **подчёркнуто мятной линией**,
цвет текста при этом не меняется. Не плашка, не второй цвет — только линия снизу.

## Пресет в EDL

```json
"preset": "scene",
"captions_style": "underline",
"theme": {
  "sceneBg": "#101114",
  "accent": "#3FE8C2",
  "badgeBg": "#131217",
  "dot": 22
}
```

Новые слои:
- `scene` — фон главы: `dark` / `light` / `color`
- `badge` — пилюля с лого или номером, с `stack` для накопления
- `bigfig` — крупная цифра или сумма
- `mockup` — скриншот в рамке телефона или окна

Карточка спикера задаётся один раз в `meta.speaker_card` и дальше не трогается.

## Почему это твой формат

| | что нужно |
|---|---|
| Съёмка | один дубль в одной точке, статичная камера, ничего не меняется |
| Свет | у тебя уже есть — Ulanzi RGB на стену даёт ровно такой цветной фон |
| Монтаж | нулевой: лицо в рамке не режется |
| Сцена | собирается кодом из `logos` и твоих скриншотов |
| Повторяемость | сто роликов на одном шаблоне, меняются только данные сцены |

Твоя библиотека из 898 SVG-лого — это прямо фабрика бейджей. У него они
нарисованы руками, у тебя соберутся автоматически по названию инструмента.
