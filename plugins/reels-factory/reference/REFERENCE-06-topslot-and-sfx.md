# Референс 06 — узкая полоса сверху + звуковой дизайн

Два разбора: раскладка `topslot` (aiwithsachi) и слоистые SFX (sultanmotions).

## Часть 1 — topslot

Разобран рилс instagram.com/reel/DdPsauap-BG.

| | |
|---|---|
| Длина | 35.9 с · 720×1280 · **24 fps** |
| Громкость | −14.2 LUFS |
| Переходов | 19 |
| Средний план | 1.9 с |

### Раскладка

```
┌─────────────────────────┐  0%
│  скриншот на всю ширину │  ← меняется каждые ~1.5 с
├─────────────────────────┤  33%
│      Introduction       │  ← субтитр НА СТЫКЕ, чёрный, одно слово
│                         │
│      лицо крупно        │  ← не прерывается весь ролик
│                         │
└─────────────────────────┘  100%
```

Не 50/50, как в `split`. **33/67** — лицо доминирует, скриншот работает
подтверждением, а не содержанием. Его не читают, на него смотрят полсекунды.

Субтитр стоит **на границе**, чёрным по светлому фону скриншота. Это решает
проблему контраста, из-за которой твой прошлый ролик проседал: текст всегда
на предсказуемом фоне, а не на пёстром интерьере.

Первые 3 секунды — отдельная обложка: карточки сертификатов парят в 3D над
головой, крупный текст белым на чёрных плашках. Дальше начинается рабочая раскладка.

### Когда брать

Когда показываешь **много разных экранов подряд** — список инструментов,
подборку сервисов, перебор вариантов. Двадцать скриншотов за 36 секунд.

## Часть 2 — звуковой дизайн

Замер моушн-рилса sultanmotions по полосам:

| Полоса | Уровень |
|---|---|
| Саб 20–120 Гц | −24.1 dB |
| **Низ 120–400** | **−20.7 dB** |
| Середина 400–2000 | −21.2 dB |
| Верх 2000–8000 | −30.8 dB |
| Воздух 8000–16000 | −38.6 dB |

**Энергия в нижней середине. Верх на 10 dB тише.**

Дешёвый SFX-микс устроен наоборот: звонкие свистящие whoosh без низа.
Отсюда ощущение «сток», а не из самих звуков.

### Слои — почему один звук не работает

Кинематографический эффект это три слоя, разнесённые по спектру и по времени:

| Слой | Время | Полоса | Задача |
|---|---|---|---|
| `transient` | 0–60 мс | верх, хайпасс от 2 кГц | щелчок, точка во времени |
| `body` | 60–500 мс | середина, бандпасс | узнаваемость эффекта |
| `tail` | 200–1500 мс | низ, лоупасс до 180 Гц, задержка 60–90 мс | вес и объём |

Один сгенерированный звук всегда даёт только `body`. Плоско.

### Плотность

Транзиенты в референсе — **раз в 1–2.5 секунды**. Не на каждое движение,
а на смысловой акцент: смена главы, появление ключевого элемента, цифра.

Звук на каждую анимацию превращается в трещотку.

### Кузница

```bash
export ELEVENLABS_API_KEY=...
python3 scripts/pipeline/sfx_forge.py --list
python3 scripts/pipeline/sfx_forge.py --all
```

Пять рецептов: `whoosh_heavy`, `impact_soft`, `ui_pop`, `riser_short`, `data_glitch`.
Каждый генерирует слои по отдельности, фильтрует по своей полосе, микширует
и нормализует. После сборки печатает спектр — сверяй с эталоном выше.

### Микс в EDL

```json
"audio": {
  "music": { "gain_db": -26 },
  "duck": { "amount_db": -6, "attack_ms": 20, "release_ms": 250 },
  "sfx": [
    { "at": 5.2, "recipe": "whoosh_heavy", "gain_db": -12, "note": "смена главы" },
    { "at": 9.8, "recipe": "ui_pop", "gain_db": -15, "note": "появился бейдж" }
  ]
}
```

`duck` приглушает музыку на время эффекта — без этого SFX и музыка
дерутся за одну полосу и оба звучат грязно.
