# Референс 03 — split-панель (saint4ai)

Третий пресет. Тот, который выглядит дорого.

Разобран рилс «4 умных коннектора для клод» (1 677 лайков).

## Технические факты

| | |
|---|---|
| Длина | 68.2 с |
| Формат | 720×1280, 30 fps |
| Громкость | −14.6 LUFS |
| Реальных переходов | ~12 |
| Средний план | **5.7 с** |
| Граница сплита | **ровно 50.0% высоты** |

Средний план почти 6 секунд — втрое медленнее yapping. И при этом не скучно.
Потому что склейки здесь не нужны: **нижняя половина кадра живёт постоянно**,
там идёт непрерывное селфи на прогулке. Движение в кадре заменяет монтажный ритм.

## Архитектура

Кадр поделён пополам, всегда одинаково:

```
┌─────────────────────────┐  0%
│  [MCP × CLAUDE]         │  ← eyebrow-пилюля, слева вверху
│                         │
│   графическая панель    │  ← заголовок / цифра / мокап
│                         │
│  Второй файлкрол.       │  ← субтитры, у самой границы
├─────────────────────────┤  50%
│                         │
│      живое селфи        │  ← A-roll, идёт непрерывно
│                         │
└─────────────────────────┘  100%
```

Панель сверху меняется, лицо снизу не прерывается. Чередуется с кадрами,
где лицо занимает весь экран — это и есть его «склейки».

## Палитра — снята пипеткой с кадров

| Роль | Цвет | Где |
|---|---|---|
| Фон панели, верх | `#303E4D` | градиент сверху вниз |
| Фон панели, низ | `#253143` | |
| **Акцент** | **`#FF7445`** | плашка ключевого слова, волна, подчёркивание |
| Цветная панель «хорошо» | `#1D6036` | крупная цифра на зелёном |
| Цветная панель «данные» | `#0F468E` | крупная цифра на синем |
| Текст активный | `#FFFFFF` | произносимое слово |
| Текст неактивный | серый ~`#8C929B` | остальная часть фразы |

**Один акцентный цвет на весь ролик.** Оранжевый. Зелёная и синяя панели —
это не второй и третий акценты, это фоны отдельных кадров, оранжевый на них не исчезает.

## Почему это выглядит дорого, а твой прошлый вариант — нет

Сравниваю с тем, что тебе не понравилось (тёмный фон, фиолетовые неоновые волны,
розовый заголовок, схема с эмодзи).

### 1. Три акцента вместо одного
У тебя: розовый + фиолетовый + циан + зелёная плашка «ШАПКА КАНАЛА».
Глазу не за что зацепиться — если акцент везде, акцента нет.
**Правило:** один цвет акцента на весь ролик. Всё остальное — белый, серый, фон.

### 2. Свечение
У тебя неоновый glow на волнах, на рамках схемы, на тексте.
У saint4ai свечения **ноль**. Тени только мягкие серые под мокапами.
Цветное свечение — самый быстрый способ получить вид шаблона из стока.

### 3. Фон соревнуется с контентом
Фиолетовые волны занимают половину внимания.
У него фон — почти плоский тёмно-синий с сеткой, которую едва видно.
**Фон должен читаться как бумага, а не как картинка.**

### 4. Две краски в одной фразе
«ИСПОЛЬЗУЙТЕ» белым, «CHATGPT» розовым, одинаковым кеглем.
Читается как два заголовка подряд.
У него акцент — подчёркнутый курсив тем же цветом, либо слово в оранжевой плашке.
Кегль не меняется, цвет текста не меняется.

### 5. Эмодзи в схеме
💡🚀🎬📝 в рамках — это мгновенно считывается как Canva.
У него в панелях **настоящие скриншоты интерфейсов**: окно коннектора, терминал, айфон.
Реальный интерфейс всегда выглядит дороже нарисованной схемы.

### 6. Нет фактуры
Плоская заливка плюс градиент. У него поверх градиента — сетка-миллиметровка
`rgba(255,255,255,0.035)`, шаг 40 px. Её почти не видно, и именно поэтому она работает:
поверхность перестаёт быть пустой, но не начинает кричать.

### 7. Подпись-бейдж
Твой `@alisovdaniel` с иконкой Instagram и строкой «ИИ · АВТОМАТИЗАЦИЯ · ВАЙБКОДИНГ» —
три уровня информации в углу. У него подписи нет вообще: ник виден в шапке поста.

## Субтитры — главная деталь

Не «белый текст с подсветкой ключевого слова», а **прогрессивная окраска**:
произнесённое и текущее слово — белые, оставшаяся часть фразы — серая.

```
Второй файлкрол.        ← «Второй» #FFFFFF, «файлкрол.» #8C929B
```

Глаз видит фразу целиком и понимает, где находится речь. Это дороже, чем
одно слово на экране, и требует ровно тех же данных из `words.json`.

## Пресет в EDL

```json
"preset": "split",
"captions_style": "progressive",
"theme": {
  "panel_top": "#303E4D",
  "panel_bottom": "#253143",
  "accent": "#FF7445",
  "grid": 40
}
```

- `panel` — новый тип слоя: `plain` / `color` / `mockup`
- граница сплита фиксирована на 50%
- A-roll снизу идёт непрерывно, `aroll_fullscreen` задаёт куски на весь экран
- валидатор: потолок статики панели 8 с (лицо снизу держит внимание)

## Когда брать

| | slides (01) | yapping (02) | **split (03)** |
|---|---|---|---|
| Средний план | 3.2 с | 1.7 с | **5.7 с** |
| Съёмка | штатив, студия | кресло, микрофон | **селфи в движении** |
| Материала | 3–5 экранов | 15–20 скриншотов | **6–10 панелей** |
| Монтажа | много | очень много | **мало** |
| Выглядит | аккуратно | живо | **дорого** |

Для тебя это лучший вариант из трёх: съёмка с руки на прогулке или в офисе,
минимум склеек, а весь «дорогой» вид делает панель, которая собирается кодом
из твоей библиотеки скриншотов и лого.
