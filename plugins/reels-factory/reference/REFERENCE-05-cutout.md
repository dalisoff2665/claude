# Референс 05 — вырезанный человек поверх карточки

Пятый пресет. Главный приём: **голова выходит за границу своей карточки.**

Разобран рилс instagram.com/reel/Ddbu9HxPWnH.

## Технические факты

| | |
|---|---|
| Длина | 21.5 с |
| Формат | 720×1280, 30 fps |
| Громкость | −14.2 LUFS |
| Переходов | 15 |
| **Средний план** | **1.4 с** |

Ритм даже быстрее yapping. Но смотрится спокойно, потому что лицо не прыгает:
меняется композиция вокруг него, а не сам кадр.

## Приём, ради которого всё

```
┌─────────────────────────┐  0%
│   светлый фон кадра     │
│  ┌───────────────────┐  │
│  │  тёмная панель    │  │  ← скриншот, скругление 24
│  └───────────────────┘  │
│       SeeDance          │  ← крупный чёрный гротеск
│         ╭───╮           │
│      волосы торчат      │  46.6%  ← макушка ВЫШЕ карточки
│  ╭──────┴───┴───────╮   │  66.2%  ← верх карточки лица
│  │   человек внутри  │   │
│  │   карточки        │   │
└──┴───────────────────┴──┘  100%
```

**Перекрытие 16.6% высоты кадра.** Слоёв два, и оба — одно и то же видео:

1. **внутри карточки** — исходник с фоном комнаты, обрезан скруглением
2. **поверх** — то же видео без фона, не обрезано ничем

Голова выходит за край, потому что верхний слой карточкой не ограничен.
Внутри карточки при этом виден настоящий интерьер — размытая стена, окно.

Плоская заливка вместо видео в первом слое убивает эффект: получится
вырезанная голова на цветном прямоугольнике.

Именно это отличает кадр от обычного сплита: в сплите человек заперт
в прямоугольнике, здесь он из него выходит. Глубина появляется бесплатно.

## Палитра

| Роль | Цвет |
|---|---|
| Фон кадра | `#C6D9E3` — светлый холодный, с текстурой стены |
| Карточка под человеком | `#A1AD9B` — приглушённый зелёный |
| Панель со скриншотом | `#181818` |
| Заголовок | чёрный гротеск Bold, крупный |

Светлая схема целиком. Ни одного тёмного экрана, кроме панели со скриншотом.

## Два типа текста — и это важно

1. **Субтитры** — белый гротеск с тенью, 2–3 слова, на лице в нижней трети
2. **Акцентные титры** — **serif-курсив**: `HIGGSFIELD`, `CATALOG`, `PAY`,
   `GENERATE`, `comment "Models"`

Второй шрифт появляется 5–6 раз за ролик на ключевых словах. Контраст
гротеска и антиквы читается как редакционная вёрстка, а не как шаблон.

Это дешёвый и сильный ход: один дополнительный шрифт меняет весь тон.

## Композиция плавает

Граница не зафиксирована, как в `split`. По кадрам:

| Время | Что |
|---|---|
| 0–3 с | панель сверху, человек в карточке снизу |
| 3–5 с | почти весь кадр светлый, человек мелко внизу, титр курсивом |
| 6–8 с | панель + карточка + заголовок между ними |
| 9–12 с | человек на весь кадр |
| 13–14 с | человек сверху, сетка картинок снизу |
| 17–21 с | человек на весь кадр, финальный титр курсивом |

Пять композиций на 21 секунду. Лицо всё время одно и то же —
меняется только, сколько вокруг него места.

## Что нужно для съёмки

- **Ровный светлый фон.** Вырез по контуру на пёстрой комнате не сделать чисто.
  Стена, или зелёный экран, или Ulanzi ровным пятном.
- **Микрофон в кадре** — он здесь часть композиции, стоит по центру внизу
- Камера не двигается вообще: композицию меняет рендер, а не оператор

## Пресет в EDL

```json
"preset": "cutout",
"theme": {
  "bg": "#C6D9E3",
  "card": "#A1AD9B",
  "panel": "#181818",
  "accentFont": "serif-italic"
}
```

Слои:
- `cutout` — человек поверх карточки: `card_top` (% высоты), `overlap` (% перекрытия)
- `panel` — тёмная карточка со скриншотом сверху
- `headline` — крупный гротеск между панелью и человеком
- `accent_title` — serif-курсив, ключевое слово

Нужны **два файла**:
- `aroll.mp4` — исходник как снял, идёт в `aroll_raw` (внутрь карточки)
- `aroll.webm` — он же без фона, идёт в `edl.aroll` (поверх)

Второй делается из первого: `make_cutout.sh raw/aroll.mp4 green`
