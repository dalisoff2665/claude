# VibeAgent FX — 20 видеоэффектов в Claude Code

Даёшь клип, на котором человек говорит в камеру, — получаешь MP4 с эффектом и родным звуком. Рендер идёт на компьютере пользователя: headless Chromium рисует каждый кадр, ffmpeg собирает видео. В интернет ничего не уходит.

## Запуск
```
node "<папка этого скилла>/engine/fx.mjs" <эффект> <клип.mp4> [--words "ТЕКСТ"] [--out итог.mp4]
node "<папка этого скилла>/engine/fx.mjs" --setup     # поставить движок заранее
node "<папка этого скилла>/engine/fx.mjs" --list      # список эффектов
```
Первый запуск ставит движок в `~/.vibeagent-fx`: Chromium для рендера, шрифты, Python-окружение (numpy, opencv, onnxruntime) и модель отделения человека от фона (Robust Video Matting, 15 МБ). Около 5 минут и ~600 МБ, один раз. Запускай с таймаутом 10 минут.

Готовый файл ложится рядом с клипом: `<имя>-<эффект>.mp4`, 1080×1350 (4:5 — лента и карусели Instagram), той же длины, со звуком исходника. Эффект проигрывается один раз на всю длину клипа и возвращает кадр к исходному дублю.

## Каким должен быть клип
- 4–8 секунд, человек говорит в камеру. Голова и плечи в кадре, над головой немного места.
- Вертикальный 9:16 или квадратный — движок сам вырежет 4:5 сверху; горизонтальный — по центру.
- SDR, не HDR (на iPhone: Настройки → Камера → Форматы → выключить HDR-видео), иначе цвета будут блёклыми.
- Фон контрастный к волосам и одежде — маска чище.

## Если что-то не так
| Симптом | Причина | Что делать |
|---|---|---|
| `Не найдено: ffmpeg…` | нет системных программ | macOS: `brew install ffmpeg python`; Windows: `winget install Gyan.FFmpeg Python.Python.3.12`; затем заново |
| `Нужен Node 18…` | старый Node | поставить LTS с nodejs.org |
| Ошибка на `playwright install` | не скачался Chromium | `cd ~/.vibeagent-fx && npx playwright install chromium`, затем `rm ~/.vibeagent-fx/.ready-*` и заново `--setup` |
| `pip`/`venv` ошибка на Linux | нет модуля venv | `sudo apt install python3-venv`, удалить `~/.vibeagent-fx/venv`, заново `--setup` |
| Рваная маска по волосам, ореол | низкий контраст фона | снять на более контрастном фоне, ровный свет спереди |
| Голова обрезана сверху, кольцо/лента не там | мало места над головой | снять шире, голова в верхней трети кадра |
| Блёклые, «серые» цвета | исходник в HDR | переснять в SDR или перекодировать `ffmpeg -i in.mov -vf zscale=t=linear,tonemap=hable,zscale=t=bt709 -c:v libx264 out.mp4` |
| Долго рендерит | рендер покадровый на CPU | норма — 2–6 кадров в секунду; 5-секундный клип ≈ 1–2 минуты |
| Изменили клип, а эффект старый | кеш подготовки по имени и времени файла | удалить `~/.vibeagent-fx/work/<клип>-*` |

Кеш подготовленных клипов лежит в `~/.vibeagent-fx/work` — его можно чистить в любой момент.
