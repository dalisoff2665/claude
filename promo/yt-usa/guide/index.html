Установка

Поставить за вечер

  1. Поставь Claude Code

    npm install -g @anthropic-ai/claude-code

    команда claude в терминале открывает чат и просит войти в аккаунт Claude.

  2. Добавь мой маркетплейс

    /plugin marketplace add dalisoff2665/claude

    маркетплейс alisov-tools в списке.

  3. Установи плагин

    /plugin install yt-usa@alisov-tools

    команды /yt-usa:… появились в подсказках после /.

  4. Подключи vidIQ

    claude mcp add --transport http vidiq https://mcp.vidiq.com/mcp

    Потом в Claude Code набери /mcp → vidiq → Authenticate и войди в vidIQ в браузере.

    vidiq со статусом connected.

  5. Подключи свой YouTube-канал

    Напиши в Claude: «подключи мой YouTube-канал к vidIQ». Он даст ссылку на вход через Google.

    название канала и число подписчиков в ответе Claude.

  6. Поставь инструменты монтажа

    brew install ffmpeg && pip install faster-whisper

    Windows: winget install Gyan.FFmpeg, затем pip install faster-whisper.

  7. Проверь всё одной командой

    /yt-usa:setup

    таблица «есть / нет / что сделать» и остаток кредитов vidIQ.

  8. Запусти канал

    /yt-usa:start

    первый вопрос про нишу. Дальше Claude ведёт по шагам и спрашивает «да» перед каждой оплатой.

Нет Claude Code? В обычном чате Claude: Settings → Connectors → vidIQ, и готовые промпты из файла PROMPTS.md.

vidIQ

Как vidIQ генерирует фото и видео

Всё оплачивается кредитами. Бесплатно — 150 в месяц: этого хватит, чтобы попробовать, но не на один ролик целиком. Для канала нужен платный план: app.vidiq.com/upgrade/mcp/claude.

ЧтоИнструментКредиты
Превью 16:9 и для шортсgenerate_thumbnail22
Доработка превью словамиrefine_thumbnail22
Видео-сцена: Seedance 2, MiniMax H3, Wan 3, Gemini Omnigenerate_videoсек × ставка × 20
Стоковый B-rollgenerate_broll1
Моушн-графика: цифры, сравненияmotion_graphics1 за 4 с

Музыка без авторских правgenerate_music25
Шортс из длинного видеоgenerate_clips9 / мин
Выбросы, ключевые слова, аналитикаoutliers, keyword_research, channel_analytics5

10-минутное видео целиком на vidIQ — около 370 кредитов. Поэтому в плагине монтаж идёт локально через ffmpeg (бесплатно), а голос — через мой клон. vidIQ остаётся там, где он сильнее всего: темы, превью, заголовки, аналитика.

Безопасность

Публикуешь ты

  • Claude не выкладывает видео и не меняет заголовки без твоего «да» с точными значениями.
  • Перед каждой платной генерацией он называет цену в кредитах.
  • Реалистичный ИИ-контент отмечается при загрузке — так требует YouTube.
  • Ключи нейросетей хранятся в .env на твоём компьютере, не в чате.
