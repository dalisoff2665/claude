# Воронка рилса «Американский YouTube» — кодовое слово ЮТУБ

```
рилс → комментарий «ЮТУБ» → ответ в комментарии → директ: гайд + плагин
     → «ГОТОВО» → первый шаг → (24 ч) помощь → (48 ч) мини-курс «11»
```

## 1. Подпись к рилсу

```
ПИШИ «ЮТУБ» В КОММЕНТАРИЯХ И ПОЛУЧИ МОЙ ПЛАГИН 👇🔥

Все говорят про американский YouTube с ИИ. Я решил попробовать: начал собирать канал — и всё сделал Claude. Сценарий, голос, картинки, монтаж.

YouTube платит и за ролики с ИИ — если они не шаблонные. Поэтому у каждого ролика свой сюжет и свой стиль: 3D, мультфильм, 2D.

Важно: с 1 февраля 2027 года порог монетизации для новых каналов вдвое выше — 8000 часов просмотра за год вместо 4000. 1000 подписчиков — как было. Кто уже в программе, тех не касается.

Что понадобилось:
— vidIQ прямо в Claude: 71 инструмент, от поиска тем до аналитики
— мой плагин yt-usa: 12 скиллов
— нейросети: голос Cartesia, персонажи и сцены — генерация

Что делает Claude:
1. Находит видео, которые набрали в 10–40 раз больше среднего по своему каналу
2. Пишет сценарий на английском и 5 хуков с оценкой
3. Озвучивает и генерит персонажей и сцены
4. Монтирует: кадры, музыка, субтитры
5. Делает превью с оценкой кликабельности и режет шортс
6. Показывает секунду, где ушли зрители, и одну правку

Публикую сам: без моего «да» Claude ничего не выкладывает.

👉 Напиши «ЮТУБ» в комментариях — пришлю гайд: что поставить, установка по шагам, плагин и промпты.

Создано с ИИ.

#claude #youtube #ютуб #нейросети #claudecode #автоматизация #ииагенты
```

## 2. Закреплённый комментарий

```
Пиши «ЮТУБ» — пришлю гайд и плагин yt-usa. Ставится одной командой в Claude Code 👇
```

## 3. Ответ в комментариях — чередовать

Одинаковый ответ на сотни комментариев Instagram считает спамом. Ротация из пяти:

1. `Отправил в директ 📩`
2. `Лови в директе — там гайд и плагин`
3. `Уже у тебя в сообщениях 👀`
4. `Готово, проверь директ`
5. `Отправил! Если не пришло — напиши «ЮТУБ» мне в директ`

## 4. Директ — сразу

```
Привет! Это Эмма, ИИ-ассистент Даниэля 🤖
Вижу комментарий «ЮТУБ» — держи гайд «YouTube USA с Claude»:
👉 <ссылка на гайд>

Внутри:
• что поставить в Claude: vidIQ и нейросети
• плагин yt-usa — 12 скиллов, ставится одной командой
• установка за вечер, по шагам
• промпты для обычного чата Claude, если нет Claude Code

Когда поставишь — напиши «ГОТОВО», подскажу первый шаг под твою нишу.
```

## 5. Ответ на «ГОТОВО»

```
Отлично 🔥 Первый шаг — команда /yt-usa:start: Claude спросит про нишу и соберёт бриф канала.
Сомневаешься, какую нишу взять? Напиши 2–3 темы, которые тебе интересны, — помогу выбрать.
```

## 6. Через 24 часа без ответа

```
Получилось поставить? Чаще всего застревают на подключении vidIQ или ffmpeg.
Напиши, на каком шаге остановился(-ась), — разберёмся.
```

## 7. Через 48 часов — следующий шаг

```
Если хочешь пройти это вместе со мной: в мини-курсе «11 ИИ-решений для бизнеса и блога»
мы по шагам собираем контент-завод, монтаж с Claude, свой сайт и ИИ-агента.
Напиши «11» — пришлю приглашение на платформу на лучших условиях.
```

## Настройка автоматизации (Boosend / CRM)

| Поле | Значение |
|---|---|
| Триггер | комментарий к этому рилсу содержит: `ютуб`, `ЮТУБ`, `Ютуб`, `youtube`, `ютюб` |
| Ответ в комментарии | случайный из блока 3 |
| Директ | блок 4, ссылка на гайд с меткой `?src=reel-yt-usa` |
| Ключевое слово «ГОТОВО» | блок 5 |
| Таймер 24 ч, нет ответа | блок 6 |
| Таймер 48 ч | блок 7 → лид в CRM со статусом «мини-курс: интерес» |
| Тег лида | `yt-usa`, источник `reel` |

Тестовая отправка — только на свой аккаунт, потом включать на рилс.
