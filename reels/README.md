# reels-factory (standalone)

Пайплайн сборки вертикальных роликов из JSON-спеки: кадры рисуются как SVG,
растрируются, склеиваются ffmpeg'ом, субтитры вшиваются через libass.

Всё детерминировано и покадрово: одна и та же спека даёт побайтово
предсказуемый хронометраж.

## Зависимости

    apt-get install -y ffmpeg librsvg2-bin
    pip install requests

Шрифт берётся из пресета (`typography.font_file`), по умолчанию DejaVu Sans Bold —
он есть в большинстве образов и полностью покрывает кириллицу.

## Пайплайн

    cd reels/scripts

    python3 validate.py mcp-connectors.json
    python3 render.py   mcp-connectors.json
    python3 publish.py  ../out/mcp-connectors.mp4 --folder reels
    python3 notify.py   --spec-id mcp-connectors --url <secure_url> \
                        --duration 11.96 --fps 24 --shots 7

## Структура

    presets/yapping.json        параметры подачи: хронометраж, палитра, типографика, вёрстка
    assets/logo_index.json      карта id -> SVG логотипа + цвет бренда
    assets/logos/*.svg          сами марки
    projects/*.json             спеки роликов
    scripts/reelkit.py          ядро: тайминг, сборка кадров, ASS-субтитры
    scripts/validate.py         проверка спеки до рендера
    scripts/render.py           SVG -> PNG -> mp4
    scripts/publish.py          подписанный upload в Cloudinary
    scripts/notify.py           уведомление в WhatsApp через Green API
    out/                        готовые ролики

## Пресет yapping

Быстрая нарезка под говорящую голову: жёсткие склейки, плашка-счётчик `01 / 05`,
логотип бренда, glow под цвет бренда, субтитры по одному слову с поп-анимацией.

Два режима рендера:

    python3 render.py spec.json                      # плотный фон, карточки на весь кадр
    python3 render.py spec.json --footage talk.mp4   # карточки поверх говорящей головы

В режиме `--footage` фон заменяется на скрим-градиент, чтобы текст читался
поверх любого видео. Футаж масштабируется по `cover` и зацикливается под
хронометраж ролика.

Озвучка подкладывается отдельно: `--audio voice.wav`. Без неё в контейнер
пишется тихая AAC-дорожка — Reels хуже жмёт видео вообще без аудио.

## Тайминг

`shot_seconds` умножается на fps и округляется до целого кадра. Это не
косметика: при 1.7 с и 24 fps выходит 40.8 кадра, и если оставить дробь,
субтитры уедут от картинки к концу ролика. Валидатор такое сообщает явно:

    WARN  1.7с x 24fps = 40.8 кадра — не целое. Округлено до 41 (1.7083с/план).
          Дрейф к концу ролика: 58 мс

Кадры внутри плана делятся между словами пропорционально длине слова, с полом
`min_word_frames`. Сумма всегда ровно равна длине плана.

## Логотипы

`assets/logo_index.json` — это просто карта путей. Марки в `assets/logos/`
нарисованы геометрией как плейсхолдеры; чтобы поставить официальные, положи их
SVG рядом и поменяй `file`. Остальной пайплайн трогать не нужно.

## Секреты

`publish.py` и `notify.py` читают ключи только из окружения либо из `.env`
в корне репозитория. `.env` в `.gitignore`, права `600` — скрипт предупредит,
если файл доступен кому-то ещё.

Green API по своей архитектуре кладёт токен в путь URL, обойти это нельзя.
Поэтому: отдельный инстанс под нотификации (не основной рабочий номер),
ротация токена раз в квартал, а в stdout `notify.py` печатает URL
с замаскированным токеном.

Cloudinary-ключ должен быть отдельным от того, что используется в n8n:
один секрет — один сервис.
