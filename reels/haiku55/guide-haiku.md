# Claude Haiku 5.5 для WhatsApp-агента: расчёт стоимости и как не попасть на ×5

*Гайд по кодовому слову ХАЙКУ · Даниэль Алисов*

7 октября вышла Claude Haiku 5.5, самая быстрая и дешёвая модель Anthropic. Для агентов в WhatsApp, Instagram и на сайте это сейчас лучшее соотношение цены и качества. Ниже: как посчитать, сколько стоит ваш агент, где подвох и как собрать агента так, чтобы он всегда работал по низкому тарифу.

---

## 1. Что важно знать про Haiku 5.5

| | Haiku 5.5 | Haiku 4.5 |
|---|---|---|
| Вход, промпт до 100K токенов | **$0.10** за 1M токенов | $1.00 |
| Выход, промпт до 100K токенов | **$0.50** за 1M токенов | $5.00 |
| Вход / выход, промпт больше 100K | **$0.50 / $2.50** | — |
| Контекст | 1M токенов | 200K |
| Уровни effort | low · medium · high · xhigh · max | нет |

- За токен модель в 10 раз дешевле Haiku 4.5. По словам Anthropic, в среднем она обходится примерно на 75% дешевле, потому что расход токенов зависит от задачи.
- ID модели в API: `claude-haiku-5-5`.
- Effort — это «сколько думать». По умолчанию стоит `medium`. Чем выше уровень, тем умнее ответ и тем больше выходных токенов вы оплачиваете.

## 2. Как посчитать стоимость одного диалога

Важная деталь: **при каждом сообщении клиента модели заново отправляется весь контекст**: системный промпт, база знаний и история переписки. Поэтому входных токенов всегда в разы больше, чем выходных.

**Формула:**

```
Стоимость диалога = (сумма входных токенов по всем запросам × цена входа)
                  + (сумма выходных токенов × цена выхода)
```

**Пример: типичный диалог WhatsApp-агента**

- 10 сообщений от клиента, значит 10 запросов к модели;
- системный промпт и выдержка из базы знаний: около 3–4K токенов;
- история растёт от сообщения к сообщению;
- в среднем ~5K токенов на входе за запрос, ~200 токенов на выходе.

| Сценарий | Вход | Выход | Итого за диалог |
|---|---|---|---|
| **Haiku 5.5**, промпт до 100K | 50K × $0.10/1M = $0.005 | 2K × $0.50/1M = $0.001 | **≈ $0.006 (~3 ₸)** |
| Haiku 4.5 | 50K × $1/1M = $0.05 | 2K × $5/1M = $0.01 | ≈ $0.06 (~30 ₸) |
| **Haiku 5.5**, каждый запрос по 120K | 1.2M × $0.50/1M = $0.60 | 2K × $2.50/1M = $0.005 | **≈ $0.60 (~300 ₸)** |

**1 000 диалогов в месяц на Haiku 5.5 стоят около $6.** Это дешевле любого тарифа сервиса автоответов.

> Посчитайте под себя: возьмите 2–3 реальных диалога из WhatsApp, прогоните через агента и посмотрите на `usage.input_tokens` и `usage.output_tokens` в ответе API. Умножьте на цены выше — получится честная цифра без догадок.

## 3. Подвох: порог 100K токенов

Если **один запрос** больше 100 000 токенов, весь этот запрос считается по высокому тарифу: $0.50 за вход и $2.50 за выход. Это в 5 раз дороже.

Как обычно на это попадают:

1. **Вся база знаний в системном промпте.** Прайс, FAQ, договоры, каталог: «пусть знает всё».
2. **Бесконечная история.** Агент получает всю переписку с клиентом за месяц.
3. **Файлы целиком.** PDF или таблица уходит в каждый запрос.

Контекст в 1M токенов — это возможность, а не повод его заполнять. Платите вы за каждый отправленный токен при каждом сообщении.

## 4. Как держать агента ниже 100K (на n8n)

**1. Окно истории, а не вся переписка.**
В ноде AI Agent подключите **Simple Memory** (раньше Window Buffer Memory) и задайте *Context Window Length* = 10–20 последних сообщений. Для длинных переписок раз в N сообщений делайте короткое саммари и храните его в Airtable или Supabase, а в промпт подставляйте саммари вместо всей истории.

**2. База знаний через поиск, а не целиком.**
Загрузите базу знаний в векторное хранилище (Supabase Vector Store или Qdrant). Подключите его к агенту как инструмент, чтобы на каждый вопрос подтягивались только 3–5 подходящих фрагментов. Обычно это 1–3K токенов вместо 80K.

**3. Короткий системный промпт.**
Роль, тон, правила, сценарии эскалации на менеджера. Всё остальное — в базе знаний. Хороший системный промпт агента продаж помещается в 1–2K токенов.

**4. Кэширование промпта.**
Неизменную часть (системный промпт, постоянные инструкции) ставьте в начало и включайте prompt caching. Повторно отправленная закэшированная часть стоит дешевле обычного входа. Актуальные цены кэша смотрите в документации Anthropic.

**5. Контроль в каждом запросе.**
После ноды модели добавьте **IF**: если `input_tokens > 80 000`, отправьте себе уведомление в Telegram или WhatsApp. Это сигнал, что где-то раздулся контекст, до того как придёт счёт.

## 5. Какой effort ставить

| Задача | Effort |
|---|---|
| Приветствие, FAQ, «сколько стоит», «где вы находитесь» | `low` |
| Обычная консультация, подбор услуги | `medium` (по умолчанию) |
| Сложный расчёт, разбор возражений, квалификация крупного лида | `high` |

**Схема-роутер:** первая дешёвая классификация на `low` («простой вопрос или сложный?»), затем основной ответ с нужным уровнем effort. Простые вопросы обходятся почти бесплатно, а умный режим включается только там, где он приносит деньги.

## 6. Чек-лист перед запуском

- [ ] Модель `claude-haiku-5-5`, ключ API хранится только в Credentials n8n, не в нодах и не в URL
- [ ] Память: окно 10–20 сообщений + саммари
- [ ] База знаний через векторный поиск, не в системном промпте
- [ ] Системный промпт до 2K токенов, неизменная часть закэширована
- [ ] Effort по задаче: `low` для FAQ, `high` только для сложного
- [ ] Алерт, если запрос > 80K токенов
- [ ] Тест на 10 реальных диалогах: средняя стоимость диалога записана в таблицу
- [ ] Переписки клиентов хранятся в отдельной базе на клиента (это персональные данные)

---

## Схема агента

```
WhatsApp (Green API webhook)
   → n8n: AI Agent (Claude Haiku 5.5, effort по роутеру)
        ├─ Memory: Simple Memory (10–20 сообщений) + саммари в Airtable
        ├─ Tool: Vector Store (база знаний, 3–5 фрагментов)
        └─ Tool: CRM / Airtable (запись лида, статус)
   → IF input_tokens > 80K → алерт
   → Green API: ответ клиенту
```
